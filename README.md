## 📌 Overview

This repository contains the code and research materials for the scientific project **"Resource-Efficient Recognition of Control Gestures"**.

The primary goal of this research is to evaluate and optimize the trade-offs between recognition accuracy, inference speed, and computational resource consumption across various neural network architectures designed for real-time control gesture recognition.


## 🏆 Achievements

* **Highest Evaluation:** In **June 2026**, this project was presented to the evaluation board from **VK** and stood out as the **only project to receive the top mark**.
