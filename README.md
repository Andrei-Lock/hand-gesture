# hand-gesture
This repository contains materail of scientifical project "resource-efficient recognition of control gestures".

This project explores the efficiency and resource consumption of various architectures for control gesture recognition.

In June 2026, it was presented to the evaluation board from VK and was the only project to receive the highest grade.

The project also features a demo website: https://alock-hand-gesture.hf.space

Thank you for your interest!
